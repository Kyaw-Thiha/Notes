## RotNet
[[RotNet(2018)|RotNet]] rotate images randomly by $0$, $90$, $180$ or $270$ degrees and make the model to predict the rotation angle.

![350](https://miro.medium.com/1*enAk96Zn6andqoBetBy5Jg.png)

So the task is multi-class classification with $4$ classes trained on [[Cross-Entropy|cross-entropy loss]], with free labels generated automatically.

# Deep RNN
[[Deep RNN]] is formed by stacking [[Recurrent Neural Network (RNN)|RNNs]] to learn more abstract representations.

![image|500](https://notes-media.kthiha.com/Deep-RNN/a278f2789e44b6bfc1c63e55d853208f.png)

- Representations in first layers are better for syntactic tasks.
- Representations in last layers are better on semantic tasks.

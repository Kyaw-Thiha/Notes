# AlexNet
[[AlexNet(2012)|AlexNet]] won the ILSVRC challenge in $2012$ by improved accuracy of ~$10\%$ from prev year.

![400](https://miro.medium.com/v2/resize:fit:1400/1*pmGLQBsuyvnQlDWGOfEQuw.png)

Compared to [[LeNet(1989)]], it has
- access to larger dataset
- increased compute
- larger model size

Speaking of model architecture and training,
- uses larger number of [[Convolution Layer|convolution layers]]
- uses [[ReLU Activation Function|ReLU activation function]] instead of [[Sigmoid Function|sigmoid]]
- uses [[Dropout|dropout]], [[Data Augmentation|data augmentation]]

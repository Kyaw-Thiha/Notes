# LeNet
[[LeNet(1989)]] is one of the first [[Convolutional Neural Network (CNN)|CNN]] introduced by Yann LeCun in 1989. 

![400](https://www.philschmid.de/static/blog/getting-started-with-cnn-by-calculating-lenet-layer-manually/lenet-5.svg)

It has $7$ layers in total:
- $2$ [[Convolution Layer]]
- $2$ [[Pooling Layer]]
- $3$ [[Neural Network|Fully Connected Layer]]

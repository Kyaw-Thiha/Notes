# VGG (Visual Geometry Group)
[[VGG(2014)]] proposed a simple architecture but with much larger no. of parameters than [[AlexNet(2012)]]. 

![400](https://viso.ai/wp-content/uploads/2024/04/vgg-16.bak.png)

It showed that stacked $3 \times 3$ [[Convolution Layer|filters]] can approximate any [[Convolution Layer|large-sized convolution]] more efficiently.

# Types of Statistical Inference
Suppose $\theta$ is the unknown parameter that we want to know.

## Estimation
- **Point Estimation**: Based on the sample observations, calculating particular value as an [[Estimator|estimate]] of the parameter $\theta$.
- **Interval Estimation**: Calculating a range of values that is likely to contain the parameter $\theta$.

## Hypothesis Testing
Based on the sample, assess whether a hypothetical value $\theta_{0}$ is a plausible value of the parameter $\theta$ or not.

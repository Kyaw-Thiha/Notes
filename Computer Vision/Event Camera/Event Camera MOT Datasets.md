# Event Camera Datasets
`EventVOT` is the main dataset for event only tracking.
`FELT` is the main dataset for event + RGB tracking.

## Event-Only MOT
- [Prophesee 1 MegaPixel](https://www.prophesee.ai/2020/01/24/prophesee-gen1-automotive-detection-dataset/)
- [Prophesee Gen1](https://www.prophesee.ai/2020/01/24/prophesee-gen1-automotive-detection-dataset/)

### Event-Only SOT
- [EventVOT](https://github.com/Event-AHU/EventVOT_Benchmark): High-resolution (1280x720) dataset with 1,141 videos of pedestrians, vehicles, UAVs [Dropbox](https://www.dropbox.com/scl/fo/fv2e3i0ytrjt14ylz81dx/h?rlkey=6c2wk2z7phmbiwqpfhhe29i5p&e=1&dl=0)
- [FE108](https://zhangjiqing.com/dataset/): Grayscale DVS indoor sequences; short-term
- `FE240Hz`: High-speed event streams (346x260)

### Event Camera + RGB SOT
- [FELT](https://github.com/Event-AHU/FELT_SOT_Benchmark): Largest long-term RGB-event tracking with occlusions, motion blur challenges.
- [COESOT](https://github.com/Event-AHU/COESOT): color-event, diverse scenes like streets/zoos with rotations, clutter.
- [VisEvent](https://github.com/wangxiao5791509/VisEvent_SOT_Benchmark): Large-scale frame-event; short-term, multi-scenario
